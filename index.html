Cada palavra (e cada par de palavras) da sua busca é uma evidência. O sistema calcula, por Naive Bayes com peso TF-IDF, a probabilidade de cada caso ser a causa real — termos raros e frases inteiras pesam mais que palavras genéricas. Sinônimos que você cadastrar (ex: "não liga" = "não pega") são reconhecidos automaticamente. Ao descartar um suspeito, a probabilidade dos demais é redistribuída. Nos casos mais importantes, você pode anexar diferenciadores — perguntas Sim/Não que ajustam a probabilidade na hora. Confirmar um caso aumenta seu peso em buscas futuras parecidas.

Adicionar caso(s)

Cole o problema e as causas prováveis — só isso já basta. O título é criado automaticamente a partir da primeira linha.
Para colar vários casos de uma vez, separe cada um com uma linha contendo apenas ---.

Dica: dentro de cada bloco você também pode incluir linhas Categoria: ... e Tags: ... logo após o título, se quiser organizar melhor.

🕵️ A Inteligência Oculta da Oficina

O algoritmo rastreia todos os seus casos, cruzando defeitos, categorias e tags para encontrar padrões que os olhos humanos deixam passar.

Clique no botão acima para o Sherlock analisar os dados da sua oficina.

🔤 Sinônimos

Ensine o sistema que frases diferentes significam a mesma coisa. Uma frase por linha dentro do mesmo grupo — a primeira linha vira a forma principal. Isso melhora a busca sem precisar reescrever nada nos casos já cadastrados.

Exportar banco de dados

Gera um arquivo .json com todos os casos, confirmações, diferenciadores e sinônimos. Use para levar o banco para outro celular, PC, ou fazer backup.

Importar banco de dados

Importa um arquivo .json exportado por este mesmo programa. Casos com título + categoria idênticos a algum já existente são ignorados — o banco só cresce, nunca duplica.

⚠️ Zona de risco

Apaga permanentemente todos os casos e sinônimos deste dispositivo. Exporte um backup antes.
